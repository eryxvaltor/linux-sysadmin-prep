# Linux System Administration Preparation

A repository for documenting my Linux system administration training, practical labs, configuration exercises, and troubleshooting notes.

## Overview

This repository tracks my preparation for an entry-level Linux system administration role. My primary learning resource is Imran Afzal's [Complete Linux Training Course to Get Your Dream IT Job](https://www.udemy.com/course/complete-linux-training-course-to-get-your-dream-it-job/) on Udemy.

The focus is on applying the concepts covered in the course through hands-on practice and maintaining clear technical documentation for future reference.

## Learning Areas

- Linux fundamentals and command-line operations
- Filesystem navigation and file management
- Users, groups, and permissions
- Package and software management
- Process and service management
- Storage and filesystem administration
- Networking fundamentals and troubleshooting
- Shell scripting and task automation
- System maintenance, security, and troubleshooting

These are the areas I plan to document as I progress; this list is not a claim of completed coursework.

## Documentation Approach

For each practical exercise, I aim to record:

1. **Objective** — What the exercise is intended to accomplish.
2. **Environment** — Distribution, version, and relevant lab setup.
3. **Procedure** — Commands and configuration changes performed.
4. **Verification** — How I confirmed the result.
5. **Troubleshooting** — Problems encountered and their resolutions.

Any credentials, private keys, tokens, or other sensitive information will be excluded from published material.
